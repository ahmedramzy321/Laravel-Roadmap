# Intermediate (4 weeks)

> **Level 2 of 3** · 4 weeks · 4 topic pages

The goal of this level is to store, query and manage data properly.
Topics go from theory to practice: design the data, query it with SQL,
learn the alternative (NoSQL), then use an ORM to work with it from code.
The SQL and NoSQL choice depends on the track. For the Laravel track:
MySQL for SQL, and MongoDB or Redis for NoSQL.

## Week by week

| Week | Topic | You finish with |
|:----:|-------|-----------------|
| 1 | [Database fundamentals](01-database-fundamentals.md) | A database design and ERD |
| 2 | [SQL](02-sql.md) | Your design built in MySQL and queried with joins |
| 3 | [NoSQL](03-nosql.md) | CRUD in one NoSQL database |
| 4 | [ORM](04-orm.md) | The same system with Eloquent models and relationships |

## Intermediate: ready for the next level when you can

-   Write SQL queries with joins against your own database design.
-   Explain why you picked SQL or NoSQL for a given problem.
-   Model relationships with Eloquent and avoid the N+1 problem.
