# Week 4 · ORM

*Topic 4 of 4 · 5 items · 3 resources*

> **Note:** the ORM for this track is Eloquent. Install Laravel and use it for models, migrations, seeders, factories and `tinker`. Controllers, routing and Blade come properly in the Advanced level (MVC).
>
> **Deliverable:** the same system from week 1 implemented with migrations, seeders, factories and Eloquent relationships.

## Explanation

-   Installation and project structure (just enough to run Eloquent)
-   Migrations, seeders and factories
-   Eloquent models and CRUD
-   Relationships: one-to-one, one-to-many, many-to-many
-   Eloquent optimization: the N+1 problem, eager loading and scopes
