# Weeks 3 and 4 · Frontend basics

*Topic 4 of 7 · 5 items · 9 resources*

> **Why here:** PHP generates HTML and receives form data, so you need to know both sides of the page. You don't need to become a frontend developer.
>
> **Deliverable:** week 3, a static personal page styled with CSS. Week 4, one JavaScript feature that calls a public API with `fetch`.

## Explanation

**Week 3: HTML and CSS**

-   HTML: structure, forms, tables
-   CSS: selectors, box model, flexbox, grid, responsive design

**Week 4: JavaScript**

-   JavaScript basics and the DOM
-   JSON and AJAX with `fetch`
-   Bootstrap or Tailwind
