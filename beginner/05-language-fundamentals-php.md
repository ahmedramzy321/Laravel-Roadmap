# Weeks 5 and 6 · Language fundamentals (PHP)

*Topic 5 of 7 · 7 items · 3 resources*

> **Deliverable:** a command-line or form-based PHP program (todo list, calculator or similar), published on GitHub.

## Explanation

**Week 5: the core of the language**

-   Syntax, variables, data types and type juggling
-   Conditions, loops and functions
-   Arrays, and basic data structures: hash maps, stacks and queues

**Week 6: PHP on the web**

-   Forms and superglobals (`$_GET`, `$_POST`)
-   Sessions and cookies
-   File handling
-   Reading the PHP documentation (make it a habit)
