# Beginner (8 weeks)

> **Level 1 of 3** · 8 weeks · 7 topic pages

The goal of this level is to get the foundations every backend developer
needs: the tools, the web, and a solid command of the language (PHP).
Topics are ordered so that each one prepares the next: how the internet
works first, then the tools, then HTTP and APIs, then the pages you'll
serve, then the language that generates them.

## Week by week

| Week | Topic | You finish with |
|:----:|-------|-----------------|
| 1 | [How the internet works](01-how-the-internet-works.md), then [Git & GitHub](02-git-and-github.md) | You can explain URL to page, and you have a GitHub repo with a branch and a pull request |
| 2 | [HTTP and APIs](03-http-and-apis.md) | You can send an HTTP request and read the response |
| 3 | [Frontend basics: HTML & CSS](04-frontend-basics.md) | A styled static page |
| 4 | [Frontend basics: JavaScript](04-frontend-basics.md) | A page that calls a public API with `fetch` |
| 5 | [Language fundamentals (1)](05-language-fundamentals-php.md) | PHP syntax, functions and arrays |
| 6 | [Language fundamentals (2)](05-language-fundamentals-php.md) | A form-based PHP program with sessions |
| 7 | [OOP](06-oop.md) | A small OOP project |
| 8 | [Advanced language features](07-advanced-language-features.md) | The same project with traits, namespaces and Composer |

## Beginner: ready for the next level when you can

-   Use Git to branch, commit, push and open a pull request.
-   Explain what happens between typing a URL and seeing a page.
-   Write PHP with functions, classes, interfaces and traits without copying a tutorial line by line.
-   Organize a project with namespaces and Composer autoloading.
