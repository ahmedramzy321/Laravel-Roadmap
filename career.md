# Career

Start this alongside the Advanced level, or earlier if you are job
hunting.

-   Interview preparation: backend and Laravel questions
-   A clean CV and a GitHub profile that shows your best projects
-   Mock interviews with other squad members
-   Contributing to open source (Optional)

## Problem solving

Start early and keep it going, because many companies test it even for
junior roles.

-   Solve two or three easy problems a week on LeetCode or HackerRank
-   Practice arrays, strings, hash maps and basic recursion first
-   Explain your solution out loud, as you would in an interview

## Get real experience

Certificates matter less than proof that you have shipped something.

-   Deploy at least one project that real people use
-   Apply for internships, freelance work or small paid tasks
-   Contribute to an open source Laravel package or fix a documented
    issue

## Soft skills

-   Read English documentation comfortably and write clear commit
    messages and pull requests
-   Get used to Agile workflows and tools such as Jira or Trello
-   Practice explaining your technical decisions in plain language

## Check the market

Before you finish Intermediate, read 15 to 20 real Laravel job listings
in your country. Note which skills repeat, and use them to decide which
advanced topics to pick. Job requirements change by region and over
time, so repeat this check every few months.
