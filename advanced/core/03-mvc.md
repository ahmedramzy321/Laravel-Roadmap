# 3. MVC

*Core topic 3 of 3 · 7 items · 8 resources*

> **Why third:** you apply SOLID and patterns while building real applications. Build MVC by hand first so Laravel doesn't feel like magic.
>
> **Deliverables:** (1) a native PHP MVC application with full CRUD. (2) a Laravel application with authentication, relationships and a dashboard (a blog, social app or portfolio with admin).

## Explanation

**Step 1: MVC by hand**

-   The MVC pattern and the request lifecycle
-   Build a small MVC app without a framework (router, controllers, views, models)

**Step 2: MVC with Laravel**

-   Routing and controllers
-   Blade templates
-   Validation and form requests
-   Authentication with Laravel Breeze, and middleware
-   File uploads and pagination
