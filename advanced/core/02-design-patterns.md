# 2. Design patterns

*Core topic 2 of 3 · 5 items · 6 resources*

> **Why second:** patterns are SOLID applied to common problems.
>
> **Deliverable:** implement three patterns (one creational, one structural, one behavioral) in small PHP examples.

## Explanation

-   Creational patterns (factory, singleton, builder)
-   Structural patterns (adapter, decorator, facade)
-   Behavioral patterns (strategy, observer)
-   Repository and service patterns
-   Know where Laravel already uses patterns (facades, factories, observers)
